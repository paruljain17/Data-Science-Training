Smart Health Diagnosis and Risk Prediction

AI-powered health risk prediction with Machine Learning and Deep Learning

About the Project

The Smart Health Diagnosis and Risk Prediction System is an AI-driven web application that predicts potential health risks based on various medical parameters. By leveraging Machine Learning (ML) and Deep Learning (DL) algorithms (Naive Bayes, SVM, KNN, Random Forest, Decision Tree, ANN, and CNN), the system offers accurate predictions and actionable health recommendations.

Key Features

  • Health Risk Prediction using ML & DL models
  • Deep Learning integration (ANN & CNN)
  • Interactive and medical-themed UI
  • AI Explainability (SHAP/LIME support)
  • Data Visualization for insights
  • Scalable and modular backend
  • Risk Score & personalized recommendations

Parameters and Their Meanings

  • Age: User's age (years).
  • Gender: Male or Female.
  • Chest Pain Type (CPT): 0 - Typical Angina, 1 - Atypical Angina, 2 - Non-Anginal Pain, 3 - Asymptomatic.
  • Resting Blood Pressure (mm Hg): Blood pressure at rest.
  • Cholesterol Level (mg/dl): Cholesterol level in blood.
  • Fasting Blood Sugar (FBS): 0 - <120 mg/dl (Normal), 1 - >120 mg/dl (Diabetes risk).
  • Resting ECG: 0 - Normal, 1 - Abnormalities detected, 2 - Left ventricular hypertrophy.
  • Maximum Heart Rate: Maximum heart rate achieved.
  • Exercise-Induced Angina (EIA): 0 - No pain, 1 - Pain during exercise.
  • Oldpeak: ST depression induced by exercise.
  • Slope: 0 - Upsloping, 1 - Flat, 2 - Downsloping.
  • Number of Major Vessels: Number of vessels colored by fluoroscopy (0–3)00.
  • Thalassemia (Thal): 0 - Normal, 1 - Fixed defect, 2 - Reversible defect.

Tech Stack

  • Frontend: HTML, CSS, JavaScript, Streamlit/Flask UI
  • Backend: Python (Flask/Streamlit)
  • Machine Learning: scikit-learn (Random Forest, SVM, KNN, Decision Tree, Naive Bayes)
  • Deep Learning: TensorFlow & Keras (ANN, CNN)
